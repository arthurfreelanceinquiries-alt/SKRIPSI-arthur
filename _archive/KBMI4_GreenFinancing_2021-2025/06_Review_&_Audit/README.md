# Review & Audit Skripsi

Direktori ini berisi seluruh instrumen evaluasi, checklist audit kelayakan naskah, log pelacakan pencarian literatur, dan review kepatuhan terhadap standar akademik FEB UKRIDA.

---

## 📋 Daftar Berkas Review & Audit

| File | Deskripsi & Fokus Audit |
| :--- | :--- |
| [`review-format.md`](review-format.md) | **Audit Format & Tata Letak:** Pemeriksaan margin 4-3-3-3, font Times New Roman 12pt, spasi 1.5, penomoran romawi/arab, format tabel *booktabs*, dan kelengkapan halaman depan sesuai Pedoman UKRIDA 2022. |
| [`review-methodology.md`](review-methodology.md) | **Audit Metodologi & Ekonometrika:** Pemeriksaan ketepatan model regresi data panel (CEM, FEM, REM), uji Chow/Hausman/LM, uji asumsi klasik, dan rasionalitas rumus rasio keuangan (ROA, Green Financing, NPL, CAR). |
| [`review-language.md`](review-language.md) | **Audit Kebahasaan & Tipografi:** Pemeriksaan tata bahasa baku PUEBI/EYD, konsistensi istilah asing (*italic*), kejelasan logika argumen antar-paragraf, dan transisi antar-bab. |
| [`review-output.md`](review-output.md) | **Audit Hasil Kompilasi & Konsistensi Data:** Verifikasi cross-check angka statistik antara Bab 4, tabel lampiran, dan naskah kompilasi final. |
| [`SEARCH_LOG.md`](SEARCH_LOG.md) | **Log Audit Pelacakan Literatur:** Catatan riwayat pencarian jurnal acuan, basis data OJK/BI, dan sumber laporan keuangan Bank KBMI 4. |
| [`WORKFLOW_LOG.md`](WORKFLOW_LOG.md) | **Log Alur Kerja:** Catatan milestone pengerjaan, iterasi revisi, dan status penyelesaian naskah. |

---

## 🎯 Panduan Penggunaan
Gunakan berkas-berkas di folder ini sebelum menyerahkan naskah ke Dosen Pembimbing atau Dewan Penguji Sidang untuk memastikan naskah telah memenuhi **100% standar kualitas bebas revisi**.
