# 📥 FOLDER DROPZONE PENGUMPULAN LAPORAN KEUANGAN & SUSTAINABILITY REPORT

> **Folder ini adalah tempat khusus penampungan file unduhan mentah.**

### 💡 Cara Pakai:
1. Setiap kali Anda men-download laporan keuangan kuartalan / sustainability report dari web Investor Relations (BRI, Mandiri, BCA, BNI) atau IDX, **langsung masukkan/paste file-nya ke dalam folder ini**.
2. **Tidak perlu pusing memikirkan nama file atau foldernya.** Taruh saja apa adanya (format PDF, Excel, zip, dsb.).
3. Beritahu asisten (atau jalankan script `organize_and_audit_reports.py`), maka:
   - File akan otomatis dianalisis (Bank apa, Tahun berapa, Kuartal Q1/Q2/Q3/Q4 atau Sustainability Report).
   - Nama file akan distandarisasi secara rapi (contoh: `BBRI_2023_Q2_Laporan_Keuangan.pdf`).
   - File akan langsung dipindahkan ke folder bank masing-masing di [`../Laporan_Keuangan_Resmi/`](../Laporan_Keuangan_Resmi/).
   - Tabel checklist status di [`../Laporan_Keuangan_Resmi/STATUS_INVENTARIS_LAPORAN.md`](../Laporan_Keuangan_Resmi/STATUS_INVENTARIS_LAPORAN.md) akan otomatis diperbarui.

### 🌐 REKOMENDASI TAUTAN UNDUHAN RESMI:

#### 🌟 1. Jalur Tercepat & Terlengkap (One-Stop Portal BEI / IDX):
> Sangat disarankan karena **keempat bank (BBRI, BMRI, BBCA, BBNI) wajib upload ke sini** per kuartal (TW1, TW2, TW3, Tahunan):
* 🔗 **[IDX - Laporan Keuangan & Tahunan](https://www.idx.co.id/id/perusahaan-tercatat/laporan-keuangan-dan-tahunan/)**
  * *Cara:* Masukkan Kode Saham (`BBRI` / `BMRI` / `BBCA` / `BBNI`) $\rightarrow$ Pilih Tahun (`2021` s.d. `2025`) $\rightarrow$ Pilih Periode (`TW1`, `TW2`, `TW3`, atau `Tahunan`) $\rightarrow$ Klik Cari.

* **BBNI (Bank Negara Indonesia):**
