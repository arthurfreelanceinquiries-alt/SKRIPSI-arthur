# Directive: SOP Highlighting Kutipan & Bukti Empiris di Mendeley Reference Manager

> **Tujuan SOP:** Memberikan panduan praktis dan daftar lokasi halaman (*page index*) serta kutipan kunci (*key quotes*) untuk memberi sorotan warna (*highlight*) pada berkas PDF di Mendeley Reference Manager, sehingga mahasiswa siap 100% membuka dan memperlihatkan bukti ilmiah secara instan saat ditanya oleh Dosen Pembimbing atau Dewan Penguji.

---

## 1. Langkah Cepat Impor & Setup di Mendeley Reference Manager

1. Buka aplikasi **Mendeley Reference Manager** di komputer Anda.
2. Klik tombol **+ Add new** $\rightarrow$ pilih **Import library** $\rightarrow$ pilih **BibTeX (.bib)**.
3. Arahkan ke berkas:
   `06_Referensi_Jurnal_PDF/Mendeley_Library_Arthur_PokemonTCG.bib`
   *(Seluruh 55 referensi skripsi akan langsung terimpor secara rapi dengan metadata lengkap)*.
4. Lampirkan berkas PDF dari folder `06_Referensi_Jurnal_PDF/` (khususnya subfolder `01_Jurnal_Empiris_Utama/`, `02_Jurnal_Teori_&_Metodologi/`, dan `03_Buku_Referensi_PDF/`) jika belum otomatis terhubung.
