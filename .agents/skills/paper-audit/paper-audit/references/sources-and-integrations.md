## Optional local skills

This bundle works on readable material without any particular plugin. Discover installed capabilities before routing:

- **research-methodology:** bounded investigation of unfamiliar methods or external literature.
- **evidence-review:** audit exact claim-to-source support and scope.
- **research-handoff:** a requested revision specification or continuation record.
- **karpathy-guidelines:** minimal, scoped, verifiable implementation changes if code fixes are requested.
- **SDD/Graph of Agents:** useful task decomposition and evidence joins; only use host capabilities actually available. No fabricated memory tiers, drift scores or voting confidence.
- **PDF/DOCX/LaTeX, statistical analysis, or relevant domain skills:** format handling or specialized checks when needed.

These names are integration hints, not hard-coded machine paths or required dependencies. Research/legal-specialist tools do not all apply to ordinary scientific manuscripts. Do not install plugins, change settings or contact services merely to satisfy this list. Respect the user's existing authorization for the actual requested task.
