# 💬 Catatan / Salinan Chat Bimbingan Dosen

File ini bisa langsung Anda pakai untuk menempelkan teks chat (WhatsApp, Email, Teams, catatan bimbingan luring, dll.) jika Anda tidak ingin mengunggah screenshot.

---

### Format Pengisian (Salin blok di bawah setiap kali ada bimbingan baru):

```markdown
## Bimbingan: [Tanggal, contoh: 9 September 2026]
- **Dosen:** [Nama Dosen Pembimbing]
- **Media:** [WhatsApp / Tatap Muka / Email / Google Meet]
- **Topik / Bab yang Dibahas:** [Contoh: Latar Belakang Bab 1 / Variabel Moderasi]

### Isi Chat / Catatan Dosen:
[Tempel teks percakapan atau poin-poin arahan dosen di sini]

### Poin Utama yang Ditekankan Dosen:
1. 
2. 
```
