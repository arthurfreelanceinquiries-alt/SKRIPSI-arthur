## 1. Inti Penelitian

### 1.1 Pertanyaan yang dijawab

Apakah motivasi hedonis, hasrat melengkapi koleksi, dan motif spekulasi finansial mendorong pembelian impulsif *booster pack* Pokémon TCG — dan apakah kontrol diri melemahkan dorongan tersebut?

### 1.2 Mengapa topik ini

- Pokémon TCG adalah waralaba media terbesar sepanjang masa (Gambar 1.1); produksi kartu tumbuh kumulatif 2019–2024 (Gambar 1.2).
- Pasar sekunder menciptakan disparitas harga ekstrem antara kartu mentah dan kartu bersertifikasi PSA 10 Gem Mint (Gambar 1.3) — hingga puluhan kali lipat harga kartu mentah.
- *Booster pack* adalah kemasan acak: pembeli tidak tahu isinya. Gabungan kejutan + kelangkaan + potensi *capital gain* menciptakan medan riset ideal untuk studi pembelian impulsif dan keuangan perilaku.
- **Kebaruan (*novelty*):** hampir seluruh riset *impulsive buying* domestik memakai konteks fesyen atau *e-commerce* umum. Konteks kolektibel spekulatif (Pokémon TCG) di skripsi manajemen Indonesia masih sangat langka.

### 1.3 Model penelitian

```
                    ┌─────────────────────┐
   X1 Hedonic ──H1──►│                     │
   Motivation        │   Y  IMPULSIVE      │
   X2 Desire ───H2──►│      BUYING         │
   for Completeness  │   (booster pack)    │
   X3 Speculative─H3►│                     │
      Motive         └─────────────────────┘
              ▲             ▲       ▲
              │H4           │H5     │H6
        M  SELF-CONTROL  (memoderasi ketiga jalur)
```

- Tiga prediktor (X1–X3) → satu variabel dependen (Y) → satu moderator (M).
- H1–H3: pengaruh positif. H4–H6: moderasi (formulasi **netral** "memoderasi" sesuai keputusan D40 — sifat pelemahan diuji di Bab IV, tidak diasumsikan di hipotesis).

## 3. Metodologi (Bab III)

| Aspek | Ketetapan |
|:---|:---|
| Desain | Kuantitatif asosiatif, *cross-sectional*, survei primer daring |
| Populasi | Konsumen/kolektor WNI ≥17 tahun dengan keterkaitan Jakarta Barat |
| Kriteria inklusi | WNI; usia ≥17; keterkaitan Jakbar (domisili / kuliah-kerja / belanja-bermain); pembelian *booster pack* resmi ≥1× dalam **12 bulan terakhir** |
| Teknik sampel | *Purposive non-probability sampling* |
| Ukuran sampel | **Minimal 111** responden *usable* (rumus Green 1991, N ≥ 50+8k untuk k=6; kunci D41 — rentang 120–150 sudah dihapus) |
| Instrumen | 27 butir Likert 5 poin: Y=6, X1=5, X2=5, X3=5, M=6 |
| Analisis | Regresi linear berganda + **MRA 2-tahap mean-centered** (Aiken & West 1991), diolah SPSS |
| Uji asumsi klasik | Normalitas, multikolinearitas (VIF/Tolerance pada variabel *centered*), heteroskedastisitas, linearitas. (D38: autokorelasi tidak relevan untuk data *cross-sectional*) |
| Alur uji hipotesis | Uji Kelayakan Model (Uji F) dulu → Uji Parsial (t) + *simple slopes* untuk H4–H6 (D43) |
| Jadwal | 6 bulan, tahun akademik 2026 (Tabel 3.3) |

## 4. Kajian Pustaka (Bab II)

Kerangka teori berlapis:

1. **Keuangan Perilaku (*Behavioral Finance*)** — landasan utama: *Speculative Motive* (Shiller 2000), bias perilaku investor (Gächter et al. 2022; Colline 2024), motif *capital gain*.
2. ***Stimulus-Organism-Response* (S-O-R)** — kerangka proses: stimulus (display, harga, kelangkaan) → organisme (emosi, hasrat) → respon (pembelian impulsif).
3. **Psikologi kolektor** — *Zeigarnik Effect* (1927) dan *Completing the Set Effect* (Gao et al. 2014): ketegangan kognitif koleksi belum tuntas.
4. **Teori regulasi diri** — *Self-Regulation Theory* (Baumeister 2002; Tangney et al. 2004): kontrol diri sebagai kapasitas penahan dorongan.
